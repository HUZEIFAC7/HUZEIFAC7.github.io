Who will fail the final exam? An ID3 decision tree, by hand and in code

Entropy and information gain computed by hand for an early-warning system, then checked line by line with a from-scratch ID3 implementation.
Machine learning · MS Data Science
Hand-written derivation (PDF)
Question

Which students are likely to fail, early enough to intervene?

Data

20 students · attendance, study hours, assignments, previous grade

Method

ID3: greedy splits on maximum information gain, no library

Output

A 5-leaf tree, 5 IF–THEN rules, predictions for 5 new students

The data

A university wants to flag students likely to fail their final exam while there is still time to help. Twenty historical records describe four habits and the result:

With 12 passes and 8 fails, the starting entropy is

\[H(S) = -\left[0.6\log_2 0.6 + 0.4\log_2 0.4\right] = 0.9710 \text{ bits},\]

close to the 1-bit maximum: knowing nothing else, we are very unsure about any student.

Choosing the root: hand versus code

ID3 picks the attribute whose split removes the most uncertainty, \(IG(S, A) = H(S) - \sum_v \frac{|S_v|}{|S|} H(S_v)\). The values in the report were derived by hand with five-decimal logarithms; the code recomputes them exactly.

9 of 9 hand-computed information gains match the code to four decimals.

The tree

The recursion stops whenever a branch is pure. Every branch here ends pure, so none of the tie-breaking rules was ever needed, and Study Hours never appears.

The code produces the same tree, read as rules:

  1. IF Previous Grade = Good THEN Pass
  2. IF Previous Grade = Poor AND Assignment = No THEN Fail
  3. IF Previous Grade = Poor AND Assignment = Yes AND Attendance = High THEN Pass
  4. IF Previous Grade = Poor AND Assignment = Yes AND Attendance = Low THEN Fail
  5. IF Previous Grade = Poor AND Assignment = Yes AND Attendance = Medium THEN Pass

What a 20-row tree can and cannot tell you

  • It fits the training data perfectly (100%), but two leaves rest on one student each. Without held-out data, its real accuracy is unknown.
  • Greedy splitting can miss useful combinations; study hours never get a say.
  • Information gain favours many-valued attributes, and ID3 cannot handle continuous values or missing data without help.
  • Next steps: more cohorts and cross-validation, C4.5 or CART with pruning, numeric features (attendance %, weekly hours), Fail-class recall as the target metric, and a fairness check before any decision about real students.

Breast cancer diagnosis: which classifier misses the fewest cancers?

Decision Tree, Random Forest and KNN compared on the Wisconsin Diagnostic data, with leakage-free tuning, error costs and threshold analysis.
Machine learning · MS Data Science
Full report (PDF) Dataset (UCI)
Question

Is a tumour malignant or benign, from 30 measurements of cell nuclei?

Data

569 patients, 30 numeric features, 37% malignant (Breast Cancer Wisconsin, Diagnostic)

Models

Decision Tree, Random Forest, K-Nearest Neighbours, tuned by 5-fold CV

Priority

Recall on malignant: a missed cancer costs far more than an extra biopsy

Stack

Python · scikit-learn 1.9 · pandas · Matplotlib

41 / 42 malignant tumours detected on the test set by the chosen KNN

97.3% test accuracy (110 of 113 correct)

0.944 Matthews correlation, robust to the class imbalance

5 / 5 reserved patients, never seen in tuning, classified correctly

Why this problem needs care

A fine-needle aspirate is imaged and the cell nuclei are measured: radius, texture, area, concavity and so on, each summarised as a mean, a standard error and a “worst” value. The classifier should support, not replace, the pathologist.

The two errors are not equal. A false negative (a cancer labelled benign) can delay treatment; a false positive costs an extra biopsy. So the project optimises for recall on the malignant class without letting specificity collapse, and checks everything with metrics that are not fooled by the 63/37 class split.

A leakage-free protocol

  1. Five patients were set aside first (stratified), only to demonstrate final predictions.
  2. The other 564 were split 80/20 with stratification: 451 training, 113 test, both with a 37% malignant rate.
  3. Imputation and scaling live inside scikit-learn pipelines, so their statistics are learned only from the data a model is fitted on. Scaling matters for KNN: feature ranges differ by a factor of more than 200,000.
  4. Each model was tuned with GridSearchCV, 5-fold stratified, scored by malignant-class F1. The test set was used exactly once.

Results on the shared test set

KNN misses one cancer, the Decision Tree two, the Random Forest three. KNN and the tree tie on accuracy (97.4%); KNN has the best recall, F1, balanced accuracy and MCC. The Random Forest is the interesting case: it is worst at the 0.5 threshold but best at ranking (ROC-AUC 0.997, log loss 0.096). Its boundary is just placed too conservatively, so three cancers fall slightly below the cut-off.

Over- and underfitting, made visible

An unrestricted tree reaches a perfect training F1 from depth 7 while validation F1 drops to about 0.90: textbook overfitting, so CV picked depth 5 (amber line). For KNN, k = 1 memorises the training data, large k over-smooths and both curves fall; k = 3 gives the best validation F1 with a small gap.

Choosing the threshold by the cost of errors

Assuming a missed cancer costs five times a false alarm (cost = 5·FN + FP), the cheapest KNN threshold was searched using out-of-fold training predictions only.

What the test set said. Lowering the threshold to 0.33 (malignant if any one of the three neighbours is malignant) was cheapest on the training folds. On the test set it caught no extra cancer (FN stayed at 1) and added 5 false alarms (specificity 97.2% → 90.1%). The default 0.5 was kept for the reported results; 0.33 remains the option for a clinic that values sensitivity above all.

Does the model learn real signal?

The ranking matches clinical knowledge: malignant nuclei are larger and more irregular. That is reassuring evidence that the models learn the biology, not artefacts.

All five are correct. Patient 4 is the instructive one: its size is in the benign range, but its worst concave points is high and only two of its three neighbours are malignant (P = 0.67). A borderline case like this should go to the pathologist for a close look, which is exactly how such a tool should be used.

Limits, stated plainly

  • With 42 malignant test cases, one patient moves recall by 2.4 points; KNN and the tree are within each other’s CV standard deviation.
  • One institution, early 1990s: performance on other equipment and populations is unknown.
  • With k = 3, KNN probabilities are coarse and poorly calibrated (log loss 0.365 vs 0.096 for the Random Forest). If calibrated risk scores were needed, the Random Forest wins.
  • The 5:1 cost ratio is an assumption, to be agreed with clinicians.
